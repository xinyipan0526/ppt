# 产品工作台使用教程

## 项目与资料

首页显示项目、资料数量、最近任务和成品版本数。进入项目后，左侧上传资料并勾选
状态为“ready”的条目；解析失败可直接重试。上传原文件和解析结果都会版本化保存。

在“创作意图”中说明受众、场景、目标、页数或风格。只上传资料、不填写文字也可
开始规划。

## 澄清与规划复核

信息不足时任务进入 `waiting_for_user`，页面根据持久化 Form Schema 渲染问题。
刷新、关闭浏览器或重启服务后仍会回到同一表单。

规划完成后会展示逐页 PageSpec。此时尚未触发主要图片费用，可以直接批准、勾选
若干页定向修改、提交整套反馈或取消任务。

## 完整 PPT 与逐页修改

生成成功后，完整幻灯片画廊是主视图。即使某一页失败，已经成功的页面仍保留并
可预览。点击页面进入检查器：

- “交付文字”：最终由确定性 HTML/CSS/SVG 排版的标题、正文和数字；
- “设计 Prompt”：图片背景、插图与装饰的生成方向；
- “局部修改”：文字修改走本地重排，视觉修改才调用图片模型；
- “历史版本”：任何恢复都会创建新 generation，不覆盖旧结果。

“全局重生成”要求填写统一方向并确认可能产生费用。它创建新的 Deck generation，
旧整套版本与单页历史不丢失。

## 恢复与导出

浏览器断开不会取消任务。工作台使用持久化快照、SSE 和有界轮询重建状态。
若出现 `recovery_required`，系统不会自动重发未知结果；先检查 Provider 控制台，再按
界面提示授权安全重试。

成品默认导出图片型 PPTX，也支持 PDF、PNG/JPG 与图片 ZIP。图片型 PPTX 保证每页
视觉一致，但不承诺 PowerPoint 元素级编辑。

## 密钥安全

API Key 只从密码表单发往同源本机服务，成功后立即清空。请不要在局部修改 Prompt、
项目名称或上传资料中粘贴 Key。浏览器 Cookie 为 HttpOnly；任何修改请求还需要 CSRF。
