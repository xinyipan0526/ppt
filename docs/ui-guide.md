# 界面使用指南

本指南按实际操作顺序介绍产品工作台。首次安装和启动请先看[快速开始](quickstart.md)。

## 1. 模型设置

确定性模式无需配置云模型。需要真实生成图片时，打开右上角“模型设置”，填写一个火山
方舟 API Key，并选择一个多模态模型和一个图片模型。

保存成功后，API Key 会立即从表单中清除，不会出现在 URL 或浏览器存储中。如果当前有
任务正在运行，新配置会显示“待激活”，并在任务结束后生效。

## 2. 创建项目和上传资料

空工作区会给出“检查模型设置 → 创建项目 → 上传资料并确认规划”的三步引导；确定性模式
无需 API Key，可直接体验完整链路。首页显示项目、资料数量、最近任务和成品版本数。创建项目后，可以上传 Markdown、PDF、
PNG、JPEG 或 WebP；状态为“ready”的资料才可以加入规划，解析失败的资料可以重试。
项目和资料都可从各自卡片删除。删除前必须在对话框中确认；请求失败时不会提前从界面移除。

在“创作意图”中说明受众、场景、目标、页数或风格。只上传资料、不填写文字也能开始规划。

## 3. 回答问题并审核规划

信息不足时，任务会进入 `waiting_for_user` 并显示澄清表单。刷新页面、关闭浏览器或重启
服务后，仍会回到同一表单。

信息充分时，首次规划由 Doubao 在一次结构化响应中返回完整的 Brief、叙事提纲、
Design System 和逐页方案，避免为了展示中间阶段而重复调用模型。只有确实需要澄清时，
用户提交答案后才会增加一次完整规划调用；后续主动修订也各自使用新的调用和版本。

规划完成后会依次展示 Brief、叙事提纲、Design System 和逐页方案。此时尚未产生主要图片费用，可以：

- 直接批准整套规划；
- 选择若干页定向修改；
- 提交整套反馈；
- 取消任务。

## 4. 查看和修改 PPT

生成完成后，画廊会显示整套幻灯片和每页质量状态。即使某一页失败，已经成功的页面仍可预览。
顶部版本选择器可浏览整套历史版本；恢复历史版本会创建新一代，不覆盖当前版本，并用
`expected_generation` 防止并发覆盖。点击页面可以查看交付文字、设计 Prompt、质量详情和历史版本，也可以执行：

- 文字或样式修改：本地重新排版，不调用图片模型；
- 视觉修改：调用图片模型，可能产生费用；
- 单页重新生成：创建新的页面版本，不覆盖旧结果；
- 全局重新生成：创建新的整套版本，旧版本仍保留。

视觉修改若需要补充定位信息，会保存为待澄清编辑。刷新或重启后仍会显示同一个问题；如果
服务端已识别目标区域，界面会沿用该区域，用户只需补充文字说明，不需要手动画框。

## 5. 任务状态、取消和恢复

浏览器断开不会取消后台任务。重新打开工作台后，页面会通过持久化快照、SSE 和有界轮询
恢复进度。默认状态区域只显示一个加载指示、当前阶段、进度和最终输出；详细 Step、Event、
Operation 与 Attempt 仅在用户打开“运行详情”后加载，不会在后台无条件请求轨迹。

运行中的任务可以在状态区域选择“取消任务”。重复取消或刷新页面不会重新执行任务。
如果出现 `recovery_required`，系统不会自动重发结果未知的远端调用；先到 Provider 控制台
核对结果，再打开“运行详情”，逐条处理“结果未知”的 Operation，确认对应 Attempt 后，才能执行
Run 级本地恢复。`waiting_for_retry` 会展示持久化的下次重试时间。项目顶部同时显示各币种的
预算上限、已结算、活动预留、未知结果占用与可用余额。

错误提示只显示安全信息。进一步排查时，可使用运行详情中可见的 Run ID、时间、Operation
或错误码，对照 `workspace/logs/ppt-agent.jsonl`。

## 6. 导出

支持以下格式：

- 图片型 PPTX；
- PDF；
- PNG ZIP；
- JPG ZIP。

图片型 PPTX 保证每页视觉一致，但不支持 PowerPoint 元素级编辑。PDF 可设置 DPI
（72–600，默认 144），JPG 可设置质量（1–100，默认 92）。

导出是持久化后台任务。关闭或刷新页面不会重复创建任务；状态变为“可下载”后才会显示
下载链接，失败后可以重新发起。若失败码为 `export_not_ready`，界面会提供“仍要强制导出”；
勾选质量风险确认后，系统会保留原格式、JPG 质量或 PDF DPI，并发送 `forced` 与风险确认文本。

## 7. 操作与密钥安全

确认对话框支持 Tab、Shift+Tab 和 Escape；提交过程中不会允许 Escape 意外中断操作。

不要把 API Key 粘贴到项目名称、资料或修改 Prompt 中。浏览器会话使用 HttpOnly Cookie，
修改请求还需要 CSRF Token。模型和密钥的详细说明见[火山方舟模型配置](provider-setup.md)。

备份、恢复、日志轮转和 Workspace 设置见[配置与运维](configuration.md)。
